Lista: Nos sirve para guardar, dentro de una misma variable, diferentes elementos. De esta forma, poder acceder a ellos, recorrerlos, cambiarlos, imprimirlos, eliminarlos, entre otras cosas. Un ejemplo de lista, podria ser una lista de compras.
Tupla: Nos sirve, también, para guardar diferentes elementos dentro de una misma variable. Sólo que, a diferencia de la lista, no se pueden agregar o quitar sus valores asi como tampoco modificarlos o cambiarlos de lugar. Son inmutables. Un ejemplo de tupla puede ser para guardar datos estructurados como, por ejemplo, unas coordenadas geográficas.
Conjunto: También es una sola variable donde se pueden guardar diferentes elementos. Su principal diferencia radica en que sus elementos son únicos, es decir, sin repetir. Un ejemplo de conjuntos puede ser una base de datos con documentos de identidad o una lista de alumnos.
Diccionario: Es una estructura de datos donde, con una sola variable, podemos guardar diferentes elementos en forma de "Clave": "valor". Es muy versatil para acceder y manipular la información dentro de la misma. Un ejemplo de diccionario podria ser uno con nombres de alumnos, comisiones y sus notas.
